# A2Z Bridge — Bộ cài đặt

Kho này chỉ chứa **bộ cài đặt** add-in A2Z Bridge for Revit (Revit 2024–2027), đăng tại mục
[Releases](https://github.com/HoangQuocTuanCivil/A2Z-Bridge-Releases/releases). Mã nguồn không công khai.

Mỗi phiên bản có hai file:

- `…-SingleUser.msi` — cài cho tài khoản Windows đang đăng nhập, không cần quyền quản trị.
- `…-MultiUser.msi` — cài cho mọi tài khoản trên máy, cần quyền quản trị.

Add-in tự kiểm tra phiên bản mới mỗi khi mở Revit và đề nghị cập nhật. Sử dụng add-in cần tài khoản
bản quyền A2Z.
